# MixVault downloads

More about MixVault: **https://getmixvault.pages.dev**

MixVault is a desktop app for DJs: pull tracks from SoundCloud, YouTube and Spotify into one crate folder, check key, BPM and quality, and carry playlists into Rekordbox.

## Download

- **Apple Silicon (M1 and later):** [MixVault-arm64.dmg](https://github.com/yobazy/mixvault-releases/releases/latest/download/MixVault-arm64.dmg)
- **Intel Macs:** [MixVault-x64.dmg](https://github.com/yobazy/mixvault-releases/releases/latest/download/MixVault-x64.dmg)
- **Windows (beta):** [MixVault-Setup.exe](https://github.com/yobazy/mixvault-releases/releases/latest/download/MixVault-Setup.exe). It isn't signed yet: when Windows says "Windows protected your PC", press **More info**, then **Run anyway**.

## Opening it the first time

MixVault isn't from an identified developer yet. Open it once, then go to **System Settings › Privacy & Security** and press **Open Anyway**.

## Free and MixVault Plus

**Free:** SoundCloud and YouTube links, and the crate tools (Inbox, Library, Clean up, tags, duplicates, loudness).

**MixVault Plus, $8 a month:** Spotify playlists with nothing to set up, lossless from Soulseek, Import (match a playlist against Rekordbox and pull only what's missing), followed playlists with automatic pulls, and the Rekordbox bridge. Ask Baz for a license key and your codeword, then send the e-transfer each month with the codeword in the message. It renews by itself.

This repo only holds the installers; the source is private.
